# 汤圆工作台

奶油底色、木咖色与雾蓝色的个人生活工作台，包含小猫与小鱼插画。

## 功能

- 总览看板：查看每日体重、支出、学习和习惯进度。
- 减重计划：记录体重、饮食与历史趋势。
- 攒钱计划：记录收支、预算与攒钱目标。
- 复习计划：管理科目、学习阶段、任务和学习时长。
- 习惯打卡与备忘录：记录坚持、便签和重要事项。
- 导出 JSON 备份。

## 存储说明

所有记录仍保存在当前浏览器的 `localStorage`，沿用存档键 `taotao.life.workspace.v1`。网页没有账号系统和同步后端，不会把记录上传至 GitHub，也不会在手机与电脑之间自动同步。

更换设备、清理浏览器或切换网站地址前，请先导出备份。浏览器会把本地预览和 GitHub Pages 视为不同来源，旧地址的记录不会自动出现在新地址。

## 部署

这是单文件静态网站，入口为 `index.html`，无需构建。GitHub Pages 使用 `main` 分支的仓库根目录。仓库只包含网页和说明，不发布本地预览截图、测试脚本与开发服务。

仓库：`1812110661-design/QRwork-dashboard`。实际公网地址以部署成功后的 GitHub Pages 地址为准。

图表优先使用 Chart.js；无法连接 CDN 时使用内嵌 SVG 图表，其余功能可继续使用。
